# 备份与恢复

桌面版、`siu-tui` 和上游 `siu` 使用 `siu-gui-backup` v1 格式。你可以用桌面版导出，在另一台机器用终端版恢复，也可以反向迁移。

## 导出与导入

| 客户端     | 导出                              | 导入                                              |
| ---------- | --------------------------------- | ------------------------------------------------- |
| 桌面版     | 设置 → 配置迁移 → 导出 JSON       | 设置 → 配置迁移 → 导入 JSON，然后确认恢复         |
| `siu-tui`  | 设置 → 导出备份，输入路径后按 `Y` | 设置 → 预览与导入备份，输入路径，检查预览后按 `Y` |
| 上游 `siu` | `E`                               | `I`                                               |

1. 在源机器导出 JSON，并将文件复制到目标机器。备份含**明文凭据**，包括 MCP 环境变量、请求头和代理账号，请妥善保管。
2. 在目标机器导入，检查 MCP、Skills 数量和兼容提示，再确认恢复。确认前如果文件发生变化，请重新预览。
3. 恢复会替换当前库中的全部已纳管 MCP、Skills、启用状态、Agent 分配和代理设置，并保留其他未纳管资源。目标 Agent 中的同名未纳管 MCP 会阻止恢复。同名未纳管 Skill 会保留在原位置，并在预览中提示。需要撤回本次恢复时，从资源库的 `backups/config-*.json` 找到刚生成的恢复前备份，用同一入口重新导入。

## 备份内容与跨机器迁移

- Skills 的文档、脚本和二进制文件均携带在 JSON 内。恢复会保留脚本可执行标记，并按目标机器的目录重建 Skills 链接。单份 JSON 最大 128 MiB，Skills 文件合计最多 64 MiB、20,000 个文件。遇到不支持的文件路径、目录链接或外部链接时，导出会报错。
- 恢复会重新映射以源用户目录或源资源库目录开头的配置路径。跨操作系统迁移后，检查绝对路径、启动命令和代理地址，并准备所需的 Agent、Node.js、Python、Docker 镜像或外部脚本。
- 备份保留尚未检测到的 Agent 的分配。装好并启动对应 Agent 后，在桌面版有写入提示时选择「重试写入」，或在 TUI 选择「设置 → 重试写入配置」。
- 桌面版导出会保存主题。导入带主题的文件时桌面版会应用该主题，导入无主题的文件时会沿用当前主题。用户级 Agent 指令文件（包括 `AGENTS.md`）独立存放，需要单独迁移。

## 自动恢复 `config.json`

将备份放到 `~/.siu/config.json`，或配置了 `SIU_HOME` 时放到 `$SIU_HOME/config.json`。桌面版和 TUI 会在启动或刷新时尝试自动恢复，先保存当前资源库备份，再用共享的 `config.applied.json` 记录已应用的文件摘要。

- 文件内容相同，后续启动或刷新会跳过恢复，保留之后的本机更改。
- 文件内容变化，下次启动或刷新会再次尝试恢复。无效文件会产生配置提示，并保留当前资源。
- 导出到这个路径后，下一次启动或刷新仍会检测该文件。删除 `config.json` 会停止后续自动恢复，已恢复的配置继续生效。
